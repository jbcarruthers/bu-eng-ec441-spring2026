## Using the Materials

### Python Scripts

All Python scripts are interactive [Marimo](https://marimo.io/) notebooks. To run them:

1. Install Marimo:
   ```bash
   pip install marimo
   ```

2. Run a notebook:
   ```bash
   marimo edit lecture_01_intro.py
   ```

3. Your browser will open with an interactive notebook interface.
